# Phase 11 Roadmap — Meta-Labeling

**Status:** PLANNED

## Goal

Estimate whether an existing deterministic setup should be taken, without replacing the strategy that generated it.

## Planned scope

Setup labels, feature snapshots, calibrated probabilities, train/validation/test discipline, and explicit skip/take outputs.

## Guardrails

No arbitrary post-hoc thresholds, no future labels in features, and no automatic universe changes.
